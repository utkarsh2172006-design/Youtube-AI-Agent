YouTube

Upload videos, manage your channel, auto-generate titles & descriptions

📤 Upload Videos 📝 Auto Titles 📊 Analytics 🗓 Scheduling
Not connected
  1. Go to console.cloud.google.com
  2. Click "New Project" → Name it "AI Content Agent"
  3. Go to APIs & Services → Library
  4. Search "YouTube Data API v3" → Enable it
  5. Go to APIs & Services → Credentials
  6. Click "Create Credentials → OAuth 2.0 Client ID"
  7. Choose "Web Application"
  8. Add Redirect URI: http://localhost:3000/auth/youtube/callback
  9. Copy Client ID and Client Secret
  10. Paste them in your .env file

Instagram

Post Reels, photos, auto-generate captions and trending hashtags

🎬 Post Reels #️⃣ Hashtags ✍️ Captions 🗓 Scheduling
Not connected
  1. Go to developers.facebook.com
  2. Click "My Apps → Create App"
  3. Choose "Business" as app type
  4. Add product: "Instagram Graph API"
  5. Go to Settings → Basic
  6. Copy App ID and App Secret
  7. Add platform: Website → http://localhost:3000
  8. Add OAuth Redirect: http://localhost:3000/auth/instagram/callback
  9. Paste them in your .env file
  10. ⚠️ Your Instagram must be connected to a Facebook Page
